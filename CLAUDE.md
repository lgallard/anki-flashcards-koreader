# AnkiFlashcards KOReader Plugin

AI-powered Anki flashcard generator for KOReader. Highlight a word or phrase on your Kobo e-reader, tap "Anki Card", and get a full flashcard — definition, IPA, synonyms, cloze sentence, and an anime-style image — generated by Qwen and sent to Anki via AnkiConnect.

## Architecture

```
Highlight → Context Extraction → AI Generation → Card Viewer → Storage / AnkiConnect
                                       ↓
                                 Image Generation (async)
```

**Data flow:**
1. User highlights text → `main.lua` captures selection + surrounding context
2. `selection_context.lua` extracts ~10 tokens before/after from the page
3. `card_generator.lua` sends phrase + context to Qwen (DashScope) → returns JSON card
4. `card_viewer.lua` shows front (definition + cloze blanked) then back (full card)
5. `image_generator.lua` generates anime-style image async (polls every 5s)
6. `card_storage.lua` persists locally as JSON; `anki_sync.lua` sends to Anki via HTTP

## File Map

All plugin code lives in `AnkiFlashcards.koplugin/`:

| File | Purpose |
|------|---------|
| `main.lua` | Entry point. Registers highlight dialog entries, orchestrates card generation |
| `card_generator.lua` | AI prompt + DashScope API call. Returns structured card JSON |
| `card_viewer.lua` | Full-screen front/back flashcard UI with edit, save, send, regenerate |
| `card_storage.lua` | Local JSON persistence (`~/.koreader/data/anki_flashcards.json`) |
| `card_manager.lua` | Card list UI — browse, filter by book, bulk send/delete |
| `anki_sync.lua` | AnkiConnect HTTP client — sends cards + images to Anki |
| `image_generator.lua` | Async Qwen image generation (wan2.2-t2i-flash) with polling |
| `highlight_inbox.lua` | Batch card creation from book highlights |
| `selection_context.lua` | Extracts surrounding text from document page |
| `settings_viewer.lua` | On-device Anki settings UI (URL, deck, tags) |
| `configuration.lua.sample` | Config template (copy to `configuration.lua` and fill in keys) |
| `_meta.lua` | Plugin metadata (name, version) |

## KOReader Patterns

**Lua version:** 5.1 (KOReader standard)

**Plugin registration:**
```lua
local MyPlugin = InputContainer:new { name = "myplugin", is_doc_only = true }
function MyPlugin:init()
    self.ui.highlight:addToHighlightDialog("unique_key", function(rhi)
        return { text = "Label", callback = function() ... end }
    end)
end
```

**Module pattern:**
```lua
local Module = {}
function Module.method(args) ... end
return Module
```

**Async:** `UIManager:scheduleIn(delay, callback)` — defers work so UI can render first

**Network:** `NetworkMgr:runWhenOnline(callback)` — prompts WiFi if offline

**Error handling:** `pcall()` for safety, functions return `(result, nil)` or `(nil, error_string)`

**UI widgets:** `Notification`, `ButtonDialog`, `InputDialog`, `ScrollTextWidget`, `ImageWidget`, `Menu`

**Text styling (PTF):** `\xEF\xBF\xB2` bold start, `\xEF\xBF\xB3` bold end — for e-ink compatible rich text

## External APIs

**DashScope (Qwen):**
- Card generation: `qwen-plus` via OpenAI-compatible chat completions endpoint
- Image generation: `wan2.2-t2i-flash` — async task creation + polling
- Auth: Bearer token via `dashscope_api_key` in config

**AnkiConnect:**
- HTTP JSON-RPC at `http://<LAN_IP>:8765`
- Actions used: `addNote`, `storeMediaFile`, `findNotes`
- Deck auto-routing: `English::<book_title>`

## Coding Conventions

- 4-space indentation
- Section headers: `-- ── Section Name ──────────────────`
- All user-facing strings wrapped in `_("...")` for i18n (gettext)
- Colors tuned for e-ink: dark orange `0x7A3500`, red `0xBB0000`, navy `0x003A75`
- Commit messages: `type: description` (feat, fix, docs, refactor)

## Configuration

- `configuration.lua` is **gitignored** (contains API keys)
- Settings can also be set on-device: highlight → Anki Manage → Anki Settings
- On-device settings are saved to `~/.koreader/data/anki_flashcards_settings.json`
- Both sources are merged at startup (on-device overrides file)

## Deployment

**Target:** Kobo e-reader (also works on Kindle, PocketBook, Android)

**Plugin path:** `/mnt/onboard/.adds/koreader/plugins/AnkiFlashcards.koplugin/`

**USB mount (macOS):** `/Volumes/KOBOeReader/.adds/koreader/plugins/AnkiFlashcards.koplugin/`

**SSH:** `root@<KOBO_IP>:/mnt/onboard/.adds/koreader/plugins/AnkiFlashcards.koplugin/`

Never deploy `configuration.lua` — credentials stay on device.

## Important Warnings

- Never `require("configuration")` in committed code — it's gitignored and device-specific
- E-ink has no color — use grayscale-friendly values (dark colors for contrast)
- E-ink refresh is slow — minimize widget redraws, use `UIManager:scheduleIn` to defer
- `UIManager:close(widget)` must reference the actual current widget — closures can go stale after `update()` recreates viewers
- AnkiConnect URL must be a LAN IP, never `localhost` (Kobo can't reach its own loopback for Anki)
- Test with `luac -p` before deploying — Lua syntax errors crash KOReader silently
